# پارسی‌اسکن — استخراج متن فارسی از اسکن مدارک اداری با تطبیق الگو

برنامه‌ی دسکتاپ (ویندوز/لینوکس/مک) برای درآوردن متن دقیق فارسی از مدارک اداری،
**بدون هوش مصنوعی و بدون سرویس آنلاین**. روش کار «تطبیق الگو» است: شکل هر تکه‌حرف
یک بار از مدارک همان اداره برداشته می‌شود و بعد هر اسکن با مقایسه‌ی پیکسلی با همان
شکل‌ها خوانده می‌شود. نتیجه قطعی و تکرارپذیر است و **هر شکلی که مطمئن نباشد با علامت ▯
مشخص می‌شود**؛ یعنی خطای پنهان ندارد.

## چه چیزی واقعاً به دست می‌آید

| نوع سند | روش | دقت |
|---|---|---|
| PDF دیجیتال (ابلاغیه‌ی سامانه‌ای، صورت‌حساب بانک) | متن از داخل فایل خوانده می‌شود، هیچ تصویری پردازش نمی‌شود | کامل؛ فقط ترتیب و شکل حروف اصلاح می‌شود |
| اسکن تایپی با فونت ثابت (نامه‌های اداری) | تطبیق الگو با پروفایل همان اداره | بالای ۹۹٪ پس از تکمیل کتابخانه؛ باقی‌مانده با ▯ مشخص می‌شود |
| اسکن تایپی با مهر و امضا روی متن | حذف جوهر رنگی، سپس تطبیق الگو | مثل بالا؛ حروفِ زیر مهر سیاه خوانده نمی‌شوند و ▯ می‌خورند |
| دست‌نویس | تشخیص داده می‌شود و صادقانه «دست‌نویس» علامت می‌خورد | با این روش قابل خواندن نیست |

خطای «صفر مطلق» با هیچ روشی وجود ندارد. تفاوت این برنامه این است که جای احتمالی
خطا را نشان می‌دهد نه اینکه چیزی از خودش حدس بزند.

## نصب و اجرا

```bat
python -m pip install -r requirements.txt
python ParsiScan.py
```

ساخت فایل اجرایی ویندوز (بدون نیاز به نصب پایتون روی دستگاه مقصد):

```bat
build_windows.bat
```

خروجی در `dist\ParsiScan\ParsiScan.exe` قرار می‌گیرد و پوشه‌ی `libraries` کنارش کپی می‌شود.

## روش کار در برنامه

1. **پروفایل بسازید** (منوی «پروفایل‌ها»). هر اداره یا هر فونت یک پروفایل است.
2. **الگوبرداری وسیع** به یکی از سه راه:
   - **خودکار از PDF دیجیتال همان اداره** (دقیق‌ترین راه؛ چون جای هر حرف داخل فایل هست، همه‌ی
     شکل‌ها بدون یک برچسب دستی و بدون خطا برداشته می‌شوند و فاصله‌ی کلمات هم کالیبره می‌شود).
   - **از فایل فونت** (`.ttf`/`.otf`) که اداره با آن تایپ می‌کند، با فهرست کلمات دلخواه.
   - **برچسب‌زنی** شکل‌های ناشناخته پس از خواندن هر اسکن: شکل‌های مشابه خوشه می‌شوند تا هر شکل فقط
     یک بار برچسب بخورد؛ پرتکرارها اول می‌آیند.
3. **استخراج**: فایل‌ها را اضافه کنید، پروفایل را انتخاب کنید. برای هر صفحه تصویر با کادر قرمز روی
   شکل‌های ناشناخته، متن با ▯ هایلایت‌شده، و جدول اعداد نشان داده می‌شود.
4. **اعداد، تاریخ‌ها و مبلغ‌ها** جداگانه اعتبارسنجی می‌شوند: تاریخ شمسی نامعتبر، گروه‌بندی سه‌رقمیِ خرابِ
   مبلغ، و رقم کنترل کد ملی نادرست به‌عنوان «مشکوک» علامت می‌خورند. ارقام چسبیده‌به‌هم به‌صورت
   چپ‌به‌راست تجزیه می‌شوند.
5. **خروجی**: TXT و Word (راست‌به‌چپ، ▯ها قرمز) و JSON با مختصات هر شکل.

## خط فرمان

```bash
python -m parsiscan profiles
python -m parsiscan bootstrap-pdf eblaghiye.pdf --profile dadgostari_bnazanin
python -m parsiscan bootstrap-font BNazanin.ttf --profile sabt --sizes 36,48,60
python -m parsiscan extract scan.pdf --profile dadgostari_bnazanin --out out
```

نسخه‌ی تحت وب هم برای استفاده در شبکه‌ی داخلی موجود است (`python app.py`) ولی رابط اصلی، برنامه‌ی دسکتاپ است.

## مراحل پردازش تصویر (همه کلاسیک و قطعی)

حذف جوهر رنگی مهر/امضا/اثر انگشت → دودویی‌سازی تطبیقی و حذف واترمارک خاکستری → حذف لکه →
تشخیص و اصلاح کجی تا ±۱۵ درجه → تشخیص جهت صفحه (۰/۹۰/۱۸۰/۲۷۰) → حذف خطوط جدول →
تفکیک خط‌ها → تفکیک تکه‌حرف‌ها (PAW) و چسباندن نقطه‌ها → تطبیق با کتابخانه →
بازسازی ترتیب اعداد → اعتبارسنجی اعداد.

## پروفایل‌های همراه

- `dadgostari_bnazanin`: از ابلاغیه‌ی الکترونیکی دادگستری (فونت B Nazanin) به‌صورت خودکار ساخته شده.
- `bank_gardeshgari_arial`: از صورت‌حساب بانک گردشگری (Arial).
- `sabt_asnad_tahoma`: نامه‌های سازمان ثبت اسناد؛ با برچسب‌زنی تکمیل می‌شود.

## ساختار کد

```
parsiscan/
  pdf_text.py    متن دیجیتال PDF + اصلاح لام‌الف و ترتیب
  preprocess.py  پاک‌سازی، کجی، جهت، حذف خطوط
  segment.py     خط‌ها و تکه‌حرف‌ها
  library.py     کتابخانه‌ی الگو و تطبیق
  bootstrap.py   الگوبرداری خودکار از PDF دیجیتال
  fontboot.py    الگوبرداری از فایل فونت
  calibrate.py   کالیبره‌ی فاصله‌ی کلمات
  numbers.py     تجزیه‌ی ارقام چسبیده و اعتبارسنجی تاریخ/مبلغ/کد ملی
  labelling.py   خوشه‌بندی شکل‌های ناشناخته برای برچسب‌زنی
  pipeline.py    اجرای کامل روی سند
  export.py      TXT / Word / JSON
  gui.py         برنامه‌ی دسکتاپ (Qt)
  cli.py         خط فرمان
app.py           نسخه‌ی وب (اختیاری)
tests/           آزمون‌ها: python -m pytest -q
```
