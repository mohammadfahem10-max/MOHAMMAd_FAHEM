# اپلیکیشن «ثبت من» — استخراج و گزارش

تهیه و تنظیم: محمدعلی کریمی‌پور

نمایش، استخراج و گزارش‌گیری از داده‌های **خودِ کاربر** در سامانهٔ «ثبت من» (my.ssaa.ir)، در همان نشستِ واردشدهٔ کاربر. **همهٔ داده روی رایانهٔ کاربر می‌ماند؛ در این مخزن فقط کد است.**

## معماری (دو لایه، بدون npm روی رایانهٔ کاربر)

| لایه | کجا اجرا می‌شود | کار |
|---|---|---|
| **رابط (Overlay)** — `رابط/` | داخل زبانهٔ واردشدهٔ کاربر (افزونهٔ Chrome/Edge یا اسکریپت کاربر) | قلاب `fetch`/`XHR` → گرفتن پاکت `{Success/success, Data/data}` → پنل تم‌طلوع با همهٔ فیلدها، شمارشگر زنده، دانلود تکی/گروهی/کلی، روند/رخداد، گزارش‌ها |
| **سرویس فایل محلی** — `بک‌اند-فایل/` | `node.exe` قابل‌حمل روی `127.0.0.1` | پایش پوشهٔ دانلود، مرتب‌سازی بسته‌ها در پوشهٔ مقصدِ انتخابی، چاپ PDF با موتور مرورگر، ساخت `فهرست.xlsx` |

پل انتقال: کانال دانلود مرورگر (بستهٔ `sabtman__*.zip`). هیچ آدرسی hardcode نشده؛ هر بخشی که سایت بخواند خودکار کشف می‌شود. الگوی «گزارشات»/«پیوست‌ها»/«دانلود فایل» هر ردیف با یک بار کلیکِ کاربر در سایت یاد گرفته می‌شود و برای همهٔ رکوردها به‌کار می‌رود.

## ساختار مخزن

```
رابط/            هستهٔ رابط (core/)، تم طلوع (theme.css)، افزونه (افزونه/)، اسکریپت کاربر (اسکریپت-کاربر/)
گزارش‌ها/         قالب رسمی (سربرگ، «تهیه و تنظیم»، مهر ضدکپی، A4) + تحلیل روند/رخداد
بک‌اند-فایل/      سرویس Node (server.js) + lib (zip, xlsx, pdf, organize) + صفحهٔ کنترل + شروع.bat
دارایی‌ها/فونت/   Vazirmatn (همراه برنامه؛ مجوز OFL)
نمونه/            دادهٔ ساختگی با همان قالب پاکت + سایت شبیه‌ساز برای آزمون
ابزار/            build.js (ساخت dist بدون هیچ وابستگی)
آزمون/            آزمون واحد (node --test) و سرتاسری (Playwright، فقط در محیط توسعه)
مستندات/          پروندهٔ کامل ساخت
```

## ساخت (در محیط توسعه)

```
node ابزار/build.js
```
خروجی در `dist/`:
- `افزونه/` → در Chrome/Edge: `chrome://extensions` → حالت توسعه‌دهنده → **Load unpacked** → این پوشه.
- `sabt-man.user.js` → نصب در Tampermonkey/Violentmonkey (جایگزین افزونه).
- `بک‌اند-فایل/` → کپی روی درایو E کاربر (مثلاً `E:\ثبت من\بک‌اند-فایل\`).

## اجرا روی رایانهٔ کاربر

1. `node.exe` قابل‌حمل را کنار `شروع.bat` بگذارید (یا در `..\node\` یا `..\سرور\`، یا متغیر `SABTMAN_NODE`). npm لازم نیست.
2. `شروع.bat` را اجرا کنید؛ صفحهٔ کنترل `http://127.0.0.1:8975/` باز می‌شود. **پوشهٔ مقصد** را انتخاب کنید (دکمهٔ «انتخاب…»). «آزمون چاپ PDF» را بزنید تا Edge/Chrome برای چاپ پیدا شود.
3. افزونه (یا اسکریپت کاربر) را نصب کنید، وارد my.ssaa.ir شوید و در بخش‌ها بگردید. دکمهٔ «ثبت من» پایین صفحه پنل را باز می‌کند.
4. یک بار در سایت روی «گزارشات» و «پیوست‌ها» یک ردیف بزنید تا الگو یاد گرفته شود؛ سپس «گرفتن روند همه» و «گرفتن پیوست‌های همه».
5. دانلود تکی/گروهی/کلی با یکی از سه حالت (PDF + متن / فقط PDF / فقط متن). بسته به پوشهٔ دانلود می‌رود و سرویس آن را در مقصد مرتب می‌کند:

```
<مقصد>/<بخش>/<نام پرونده>/
   ۱ اسناد/            فایل اصل، دست‌نخورده، با نام اصل
   ۲ پیوست‌ها/         پیوست‌ها با نام اصل
   ۳ روند و رخدادها/   کارنامهٔ روند (PDF) + روند (json)
   ۴ گزارش‌ها/         برگهٔ رکورد (PDF) + متن (txt، md) + json
   فهرست.xlsx          فهرست فایل‌ها + برگهٔ روند
```

«گزارش‌ها» در هر بخش: جدول کامل، خط زمانی هر رکورد، مدت هر مرحله، جریان وضعیت، شمارش‌ها، روزانه/ماهانه/ساعتی، معطل‌ها، رویت‌نشده‌ها، تازه‌ها؛ خروجی PDF رسمی + md + Excel.

«نقشهٔ کشف‌شده» (دکمهٔ بالای پنل): فقط مسیرهای ماسک‌شده و نام فیلدها، بدون هیچ مقداری — برای دقیق‌ترکردن نگاشت.

## قانون‌های رعایت‌شده
- فقط کد در مخزن؛ داده هرگز (قانون ۵۱/۵۴). نام فایل‌ها و پوشه‌های خروجی فارسی (۵۹). فایل اصل دست‌نخورده (۷۱). عینِ داده با ارقام فارسی (۷۲).
- خروجی‌های رسمی: «تهیه و تنظیم: محمدعلی کریمی‌پور»، مهر کم‌رنگ ضدکپی مورب، سربرگ ثابت، چاپ A4 بدون نصف‌شدن ردیف، بی‌نشانهٔ هوش مصنوعی (۶۲/۶۴/۶۵).
- نشست: اگر پایان یافت، پیام «دوباره وارد شوید» و ادامهٔ صف از همان‌جا؛ هیچ دورزدنی نیست.

## آزمون

```
npm test                       # واحد: پاکت، تخت‌کردن، تاریخ جلالی، ZIP، انبار، گزارش‌ها، xlsx، مرتب‌سازی، PDF
node آزمون/e2e-overlay.js      # سرتاسری روی سایت شبیه‌ساز (Playwright)
node آزمون/e2e-extension.js    # بارگذاری افزونه در Chromium + پل دانلود
node نمونه/serve.js            # سایت شبیه‌ساز: http://127.0.0.1:8765/portal
```

## محدودیت صادقانه
این کد بدون دسترسی به my.ssaa.ir و نشست کاربر نوشته و روی **دادهٔ ساختگی** آزموده شده است. نام فیلدهای واقعی (به‌جز الگوی پاکت و دو مسیر کشف‌شده) حدس زده نشده؛ رابط همهٔ فیلدها را عمومی نمایش می‌دهد. آزمون نهایی روی رایانهٔ کاربر با دادهٔ واقعی انجام می‌شود و ایرادها برمی‌گردد.
