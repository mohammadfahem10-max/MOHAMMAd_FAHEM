# اپلیکیشن «ثبت من» — استخراج و گزارش

تهیه و تنظیم: محمدعلی کریمی‌پور

نمایش، استخراج و گزارش‌گیری از داده‌های **خودِ کاربر** در سامانهٔ «ثبت من» (my.ssaa.ir)، در همان نشستِ واردشدهٔ کاربر. **همهٔ داده روی رایانهٔ کاربر می‌ماند؛ در این مخزن فقط کد است.**

## معماری (یک اپلیکیشن ویندوزی مستقل؛ بدون افزونه، بدون npm)

| لایه | کجا اجرا می‌شود | کار |
|---|---|---|
| **پوستهٔ ویندوزی** — `پوسته-ویندوزی/` | «ثبت من.exe» (WPF + WebView2، کامپایل با `csc` خود ویندوز) | سایت my.ssaa.ir درون پنجره؛ تزریق رابط پیش از کد سایت؛ دریافت بسته‌ها با `postMessage` و نوشتن مستقیم روی دیسک؛ انتخاب پوشهٔ مقصد؛ اجرای پنهان سرویس Node و خاموش‌کردن آن با بستن پنجره |
| **رابط (Overlay)** — `رابط/` | تزریق‌شده در WebView2 (فقط قاب اصلی و دامنهٔ ssaa.ir) | قلاب `fetch`/`XHR` → پاکت `{Success/success, Data/data}` → پنل تم‌طلوع با همهٔ فیلدها، شمارشگر زنده، دانلود تکی/گروهی/کلی، روند/رخداد، گزارش‌ها |
| **سرویس فایل** — `بک‌اند-فایل/` | `node.exe` قابل‌حمل، پنهان، فقط `127.0.0.1` | مرتب‌سازی بسته‌ها در پوشهٔ مقصد، چاپ PDF با موتور مرورگر، ساخت `فهرست.xlsx` |

هیچ آدرسی hardcode نشده؛ هر بخشی که سایت بخواند خودکار کشف می‌شود. الگوی «گزارشات»/«پیوست‌ها»/«دانلود فایل» هر ردیف با یک بار کلیکِ کاربر در سایت یاد گرفته می‌شود و برای همهٔ رکوردها به‌کار می‌رود.

## ساختار مخزن

```
پوسته-ویندوزی/    کد C# پوسته (src/)، ساخت.cmd، مانیفست، exe.config
رابط/            هستهٔ رابط (core/: قلاب، انبار، پل پوسته، خروجی، پنل)، تم طلوع (theme.css)
گزارش‌ها/         قالب رسمی (سربرگ، «تهیه و تنظیم»، مهر ضدکپی، A4) + تحلیل روند/رخداد
بک‌اند-فایل/      سرویس Node (server.js) + lib (zip, xlsx, pdf, organize) + صفحهٔ کنترل + شروع.bat
دارایی‌ها/فونت/   Vazirmatn (همراه برنامه؛ مجوز OFL)
نمونه/            دادهٔ ساختگی با همان قالب پاکت + سایت شبیه‌ساز برای آزمون
ابزار/            build.js (ساخت dist بدون هیچ وابستگی)
آزمون/            آزمون واحد (node --test) و سرتاسری (Playwright، فقط در محیط توسعه)
مستندات/          پروندهٔ کامل ساخت
```

## ساخت

```
node ابزار/build.js          # dist/پوسته-ویندوزی/: رابط.js + بک‌اند-فایل + فونت + کد C# + ساخت.cmd
پوسته-ویندوزی\ساخت.cmd       # روی ویندوز: csc → «..\..\اپلیکیشن ثبت من\برنامه\ثبت من.exe» (+ رابط.js، بک‌اند-فایل، node.exe)
```
جزئیات (DLLهای WebView2، مسیر node.exe، متغیرها) در `پوسته-ویندوزی/README.md`.

## اجرا روی رایانهٔ کاربر

1. دوبار کلیک روی «ثبت من.exe» — یک پنجره با تم طلوع؛ سایت my.ssaa.ir درون آن باز می‌شود و همان‌جا وارد شوید.
2. نوار بالا: «نمایش سایت / نمایش داده‌ها»، «انتخاب پوشهٔ مقصد»، «باز کردن پوشهٔ مقصد»، «تنظیمات». هیچ کنسول یا صفحهٔ localhost نمایش داده نمی‌شود.
3. در بخش‌ها بگردید؛ دکمهٔ «ثبت من» پایین صفحه پنل داده را باز می‌کند. یک بار روی «گزارشات» و «پیوست‌ها» یک ردیف بزنید تا الگو یاد گرفته شود؛ سپس «گرفتن روند همه» و «گرفتن پیوست‌های همه».
4. دانلود تکی/گروهی/کلی با یکی از سه حالت (PDF + متن / فقط PDF / فقط متن). بسته با postMessage به پوسته می‌رسد و مستقیم در مقصد مرتب می‌شود:

```
<مقصد>/<بخش>/<نام پرونده>/
   ۱ اسناد/            فایل اصل، دست‌نخورده، با نام اصل
   ۲ پیوست‌ها/         پیوست‌ها با نام اصل
   ۳ روند و رخدادها/   کارنامهٔ روند (PDF) + روند (json)
   ۴ گزارش‌ها/         برگهٔ رکورد (PDF) + متن (txt، md) + json
   فهرست.xlsx          فهرست فایل‌ها + برگهٔ روند
```

«گزارش‌ها» در هر بخش: جدول کامل، خط زمانی هر رکورد، مدت هر مرحله، جریان وضعیت، شمارش‌ها، روزانه/ماهانه/ساعتی، معطل‌ها، رویت‌نشده‌ها، تازه‌ها؛ خروجی PDF رسمی + md + Excel.

«نقشهٔ کشف‌شده» (دکمهٔ بالای پنل): فقط مسیرهای ماسک‌شده و نام فیلدها، بدون هیچ مقداری — برای دقیق‌ترکردن نگاشت.

## قانون‌های رعایت‌شده
- فقط کد در مخزن؛ داده هرگز (قانون ۵۱/۵۴). نام فایل‌ها و پوشه‌های خروجی فارسی (۵۹). فایل اصل دست‌نخورده (۷۱). عینِ داده با ارقام فارسی (۷۲).
- خروجی‌های رسمی: «تهیه و تنظیم: محمدعلی کریمی‌پور»، مهر کم‌رنگ ضدکپی مورب، سربرگ ثابت، چاپ A4 بدون نصف‌شدن ردیف، بی‌نشانهٔ هوش مصنوعی (۶۲/۶۴/۶۵).
- نشست: اگر پایان یافت، پیام «دوباره وارد شوید» و ادامهٔ صف از همان‌جا؛ هیچ دورزدنی نیست.

## آزمون

```
npm test                       # واحد: پاکت، تخت‌کردن، تاریخ جلالی، ZIP، انبار، گزارش‌ها، xlsx، مرتب‌سازی، PDF
node آزمون/e2e-overlay.js      # سرتاسری روی سایت شبیه‌ساز (Playwright)
node آزمون/e2e-shell-bridge.js # پل postMessage پوستهٔ ویندوزی (شبیه‌سازی chrome.webview)
node نمونه/serve.js            # سایت شبیه‌ساز: http://127.0.0.1:8765/portal
```

## محدودیت صادقانه
این کد بدون دسترسی به my.ssaa.ir و نشست کاربر نوشته و روی **دادهٔ ساختگی** آزموده شده است. کد C# پوسته در محیط توسعه کامپایل نشده (csc نیست) و روی رایانهٔ کاربر با `ساخت.cmd` آزموده می‌شود. نام فیلدهای واقعی (به‌جز الگوی پاکت و دو مسیر کشف‌شده) حدس زده نشده؛ رابط همهٔ فیلدها را عمومی نمایش می‌دهد. آزمون نهایی روی رایانهٔ کاربر با دادهٔ واقعی انجام می‌شود و ایرادها برمی‌گردد.
