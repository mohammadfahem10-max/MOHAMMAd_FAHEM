# پوستهٔ ویندوزی «ثبت من» (WPF + WebView2)

شکل قطعی برنامه (بخش ۸ دستور کار): **کاربر هرگز سایت را نمی‌بیند.**
- **WebView2ِ پنهان** سایت my.ssaa.ir را زنده نگه می‌دارد؛ `قلاب.js` (قلاب fetch/XHR + رله + خودکارسازی) پیش از کد سایت تزریق می‌شود.
- **WebView2ِ دیدنی** صفحه‌های خود برنامه را نشان می‌دهد (`برنامه/index.html` از میزبان مجازی `https://app.sabtman/`): ورود (کد ملی → ارسال کد → کد پیامکی، با نمایش کپچای سایت اگر بود)، «در حال گردآوری»، پیشخوان با شمار داده‌های هر بخش، صفحهٔ هر بخش (همهٔ کلیدهای بخش ۷)، گزارش‌ها، تنظیمات (پوشهٔ مقصد، حالت پیش‌فرض، تم، اندازهٔ نوشته)، خروج از حساب.
- پوسته فقط **رله** است: پیام‌های `site` از سایت به رابط، `site-cmd` از رابط به سایت؛ بستهٔ کار (`job`) در `داده\صف` نوشته می‌شود و سرویس Nodeِ پنهان (که با بستن پنجره خاموش می‌شود) آن را در پوشهٔ مقصد مرتب و PDF می‌کند.
- سرعت گردآوری تطبیقی (بخش ۱۰): بیشینهٔ ایمن با پس‌کشیدن خودکار بر ۴۲۹/۴۰۳/کندی؛ بخش‌های سنگین‌تر اول؛ ادامه از همان رکورد پس از ورود دوباره. هیچ محافظی دور زده نمی‌شود.

## فایل‌ها
| فایل | کار |
|---|---|
| `src/Program.cs` | Mutex تک‌نمونه، اجرای پنجره |
| `src/MainWindow.cs` | دو WebView2، رله، ذخیرهٔ فایل، انتخاب پوشه، خروج (پاک‌کردن کوکی‌ها)، پنجرهٔ جدا برای «ورود از طریق دولت من» |
| `src/ServiceHost.cs` | node.exe پنهان + Job Object |
| `src/Backdrop.cs` | شیشهٔ ویندوز ۱۱ (میکا) مانند Host.cs میزبان |
| `src/Paths.cs` | مسیرها، تنظیمات (`داده\تنظیمات.json`: اندازه و جای پنجره، مقصد، …)، گزارش کار |
| `پیکربندی-سایت.json` | انتخابگرهای فرم ورود/منو/دکمه‌ها؛ **بی کامپایل دوباره** اصلاح می‌شود (روی رایانهٔ کاربر با باز بودن سایت تنظیم شود) |
| `ساخت.cmd` | csc چارچوب ۴.۰ (C# 5) → «برنامه\ثبت من.exe» + کپی قلاب.js، برنامه\، بک‌اند-فایل، node.exe، DLLهای WebView2، و نوشتار/رنگ/تم‌های میزبان (`SABTMAN_MIZBAN_UI`) |

## ساخت
```
پوسته-ویندوزی\ساخت.cmd
```
متغیرها (اختیاری): `SABTMAN_WEBVIEW2` (پوشهٔ DLLها)، `SABTMAN_NODE` (node.exe)، `SABTMAN_MIZBAN_UI` (پوشهٔ «اپلیکیشن میزبان\رابط» برای themes.js، app.css و فونت Vazirmatn UI FD)، `SABTMAN_OUT`.

## تم‌ها و نوشتار (بخش ۹)
اگر `برنامه\themes.js` میزبان کپی شده باشد (`THEMES` و `Theme.apply`)، همهٔ تم‌های میزبان در تنظیمات فهرست می‌شوند؛ وگرنه تم‌های پیش‌فرض (طلوع/روشن/تیره). فونت `Vazirmatn UI FD` اگر در `برنامه\font` باشد به کار می‌رود؛ وگرنه Vazirmatn همراه.

## آزمون بدون ویندوز
`node آزمون/e2e-app.js`: دو صفحهٔ Chromium نقش دو WebView2 و Node نقش پوسته را دارد — ورود، گردآوری، پیشخوان، دانلود، تنظیمات، پایان نشست.
